🌱 Plant care lives in Telegram

Use the Telegram bot to add plants, update care schedules, record watering, snooze reminders, and manage notification settings.

Reminders start turned off. A reminder never records watering; only the Watered button updates a plant's history and next date.

  1. Set up the bot using the instructions in the project README.
  2. Open the bot in Telegram and send /start.
  3. Use My plants, Add plant, Watering / Status, and Settings.
