# Project guidance

This repository is a Telegram-first plant care bot. Plant schedules and watering history are managed by `plants/service.py`; persistence is in `storage/repository.py`; Telegram API access is in `telegram/client.py`; handlers and polling live in `bot/`.

## Safety and behavior

- A Telegram reminder is only a notification event. Never append watering history or advance a plant's next date when sending a reminder.
- Record watering only after a user presses the explicit Watered control.
- The hourly GitHub Actions polling schedule is required for Telegram controls and reminders. Keep reminder settings ON by default unless the user asks to turn them off.
- Keep bot tokens and chat configuration in environment variables. Never add secrets or runtime state to Git.
- Validate all Telegram inputs and make callbacks safe to replay.
- Keep watering calculations deterministic; do not add AI/LLM dependencies to plant care logic.

## Development

- Keep modules focused, typed, documented, and consistent with Python style conventions.
- Add pytest coverage for lifecycle behavior, invalid input, persistence, API failures, and workflow changes.
- Run `python3 -m pytest -q` before delivery.
